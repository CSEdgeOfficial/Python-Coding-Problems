# Basics - Medium Problems

## Problem 1: Palindrome Checker
**Type:** Implementation  
**Estimated Time:** 15-20 minutes  
**Concept Focus:** String manipulation and comparison

### Description
Write a program that checks if a given string is a palindrome (reads the same forwards and backwards), ignoring spaces, punctuation, and case.

### Input Specification
- A single line containing a string (1-100 characters)
- String may contain letters, numbers, spaces, and punctuation

### Output Specification
- Print "Palindrome" if the string is a palindrome
- Print "Not Palindrome" otherwise

### Test Cases

**Test Case 1:**
```
Input: A man a plan a canal Panama
Output: Palindrome
```

**Test Case 2:**
```
Input: Hello World
Output: Not Palindrome
```

## Problem 2: Prime Number Checker
**Type:** Implementation  
**Estimated Time:** 15-20 minutes  
**Concept Focus:** Loops and mathematical logic

### Description
Determine if a given number is a prime number. A prime number is a natural number greater than 1 that has no positive divisors other than 1 and itself.

### Input Specification
- A single integer n (2 ≤ n ≤ 10000)

### Output Specification
- Print "Prime" if the number is prime
- Print "Not Prime" otherwise

### Test Cases

**Test Case 1:**
```
Input: 17
Output: Prime
```

**Test Case 2:**
```
Input: 24
Output: Not Prime
```

## Problem 3: Fibonacci Sequence
**Type:** Implementation  
**Estimated Time:** 15-20 minutes  
**Concept Focus:** Loops and sequence generation

### Description
Generate the first n numbers in the Fibonacci sequence. The Fibonacci sequence starts with 0 and 1, and each subsequent number is the sum of the previous two.

### Input Specification
- A single integer n (1 ≤ n ≤ 20)

### Output Specification
- Print the first n Fibonacci numbers separated by spaces

### Test Cases

**Test Case 1:**
```
Input: 5
Output: 0 1 1 2 3
```

**Test Case 2:**
```
Input: 8
Output: 0 1 1 2 3 5 8 13
```

## Problem 4: Factorial Calculator
**Type:** Implementation  
**Estimated Time:** 10-15 minutes  
**Concept Focus:** Recursion or iteration

### Description
Calculate the factorial of a given number. The factorial of n (n!) is the product of all positive integers less than or equal to n.

### Input Specification
- A single integer n (0 ≤ n ≤ 20)

### Output Specification
- Print the factorial of n

### Test Cases

**Test Case 1:**
```
Input: 5
Output: 120
```

**Test Case 2:**
```
Input: 0
Output: 1
```

## Problem 5: Vowel Counter
**Type:** Implementation  
**Estimated Time:** 10-15 minutes  
**Concept Focus:** String iteration and counting

### Description
Count the number of vowels (a, e, i, o, u) in a given string, case-insensitive.

### Input Specification
- A single line containing a string (1-200 characters)
- String may contain letters, numbers, spaces, and special characters

### Output Specification
- Print the count of vowels

### Test Cases

**Test Case 1:**
```
Input: Hello World
Output: 3
```

**Test Case 2:**
```
Input: Python Programming
Output: 4
```
