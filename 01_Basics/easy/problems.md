# Basics - Easy Problems

## Problem 1: Hello World
**Type:** Implementation  
**Estimated Time:** 5-10 minutes  
**Concept Focus:** Basic input/output operations

### Description
Write a Python program that takes a name as input and prints a greeting message.

### Input Specification
- A single line containing a string (the name)
- Name will be 1-50 characters long
- Name contains only alphabetic characters and spaces

### Output Specification
- Print "Hello, [name]!" where [name] is the input

### Test Cases

**Test Case 1:**
```
Input: Alice
Output: Hello, Alice!
```

**Test Case 2:**
```
Input: John Doe
Output: Hello, John Doe!
```

## Problem 2: Simple Calculator
**Type:** Implementation  
**Estimated Time:** 10-15 minutes  
**Concept Focus:** Arithmetic operations and conditionals

### Description
Create a simple calculator that takes two numbers and an operator (+, -, *, /) and returns the result.

### Input Specification
- First line: A float number (operand1)
- Second line: An operator (+, -, *, or /)
- Third line: A float number (operand2)
- For division, operand2 will never be 0

### Output Specification
- Print the result rounded to 2 decimal places

### Test Cases

**Test Case 1:**
```
Input:
10
+
5
Output: 15.00
```

**Test Case 2:**
```
Input:
20
/
4
Output: 5.00
```

## Problem 3: Even or Odd
**Type:** Implementation

**Concept Focus:** Conditional statements and modulo operator

## Problem 4: Temperature Converter
**Type:** Implementation  
**Estimated Time:** 10-15 minutes  
**Concept Focus:** Mathematical formulas and type conversion

### Description
Convert temperature from Celsius to Fahrenheit and Kelvin.

### Input Specification
- A float number representing temperature in Celsius (-273.15 ≤ temp ≤ 1000)

### Output Specification
- First line: Temperature in Fahrenheit rounded to 2 decimal places
- Second line: Temperature in Kelvin rounded to 2 decimal places

### Formulas
- Fahrenheit = (Celsius × 9/5) + 32
- Kelvin = Celsius + 273.15

### Test Cases

**Test Case 1:**
```
Input: 0
Output:
32.00
273.15
```

**Test Case 2:**
```
Input: 100
Output:
212.00
373.15
```
