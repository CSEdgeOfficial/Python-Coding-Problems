# Data Structures - Easy Problems

## Problem 1: List Sum
**Type:** Implementation  
**Estimated Time:** 5-10 minutes  
**Concept Focus:** Lists and basic operations

### Description
Calculate the sum of all elements in a list of integers.

### Input Specification
- First line: An integer n (1 ≤ n ≤ 100) - number of elements
- Second line: n space-separated integers (-1000 ≤ each integer ≤ 1000)

### Output Specification
- Print the sum of all elements

### Test Cases

**Test Case 1:**
```
Input:
5
1 2 3 4 5
Output: 15
```

**Test Case 2:**
```
Input:
4
-10 20 -5 15
Output: 20
```

## Problem 3: List Reverser
**Type:** Implementation  
**Estimated Time:** 10 minutes  
**Concept Focus:** List manipulation

### Description
Reverse the order of elements in a list.

### Input Specification
- First line: An integer n (1 ≤ n ≤ 100)
- Second line: n space-separated integers

### Output Specification
- Print the reversed list elements separated by spaces

### Test Cases

**Test Case 1:**
```
Input:
5
1 2 3 4 5
Output: 5 4 3 2 1
```

**Test Case 2:**
```
Input:
3
10 20 30
Output: 30 20 10
```

## Problem 4: Count Occurrences
**Type:** Implementation  
**Estimated Time:** 10-15 minutes  
**Concept Focus:** Lists and counting

### Description
Count how many times a specific element appears in a list.

### Input Specification
- First line: An integer n (1 ≤ n ≤ 100)
- Second line: n space-separated integers
- Third line: An integer x to search for

### Output Specification
- Print the count of occurrences of x

### Test Cases

**Test Case 1:**
```
Input:
7
1 2 3 2 4 2 5
2
Output: 3
```

**Test Case 2:**
```
Input:
5
10 20 30 40 50
100
Output: 0
```

## Problem 5: Tuple to List
**Type:** Implementation  
**Estimated Time:** 10 minutes  
**Concept Focus:** Tuple and list conversion

### Description
Convert a tuple of integers to a list and add a new element at the end.

### Input Specification
- First line: An integer n (1 ≤ n ≤ 100)
- Second line: n space-separated integers (tuple elements)
- Third line: An integer to add

### Output Specification
- Print the resulting list elements separated by spaces

### Test Cases

**Test Case 1:**
```
Input:
3
1 2 3
4
Output: 1 2 3 4
```

**Test Case 2:**
```
Input:
2
10 20
30
Output: 10 20 30
```
